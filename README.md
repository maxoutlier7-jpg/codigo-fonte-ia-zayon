# Nova Airis — protótipo Python

Nova Airis é um protótipo desktop em Python com interface sci-fi escura, núcleo animado, painel de estado e campo de conversa.

## Requisitos
- Python 3.10+
- PySide6

## Executar no Linux Mint
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Esta primeira versão é a base visual da aplicação. A conversa ainda funciona como protótipo local; a integração com provedores de IA, voz local e Teia Cognitiva será implementada em módulos separados, sem fingir que já estão conectados.
